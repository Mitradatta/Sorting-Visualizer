About: Sorting Visualiser

Welcome to the tool that visualises the existing sorting algorithms in an interactive way. Sorting plays a key role in algorithms with respect to important applications including filters,sort by recommendations and a lot more. This tool is developed to let the users understand the working of each specific Algorithm.

How to use

  1. Select a sorting algorithm

  2. Click on to start the simulation

 Algorithm: Bubble Sort

        
    Bubble Sort(arr, size)
        n = size
        for i=0 to n-1
            for j=0 to n-2
                if arr[j]>arr[j+1]
                    Swap arr[j] and arr[j+1]
                end-if
            end-for
        end-for 

    Time Complexity : O(n2)

 Algorithm: Insertion Sort

            
    Insertion Sort(arr, size)
        n = size
        for i=0 to n
            temp = arr[i]
            j=i+1
            while(j>0 and arr[j]>temp)
                arr[j+1] = arr[j]
                j=j-1
            end-while
            arr[j+1] = temp
        end-for 
        Time Complexity : O(n2)
